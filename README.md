
# AgriMatch AI


ระบบตลาดกลางสินค้าเกษตรอัจฉริยะ (AI-Powered Agricultural Marketplace)

## รายละเอียดโครงงาน

AgriMatch AI เป็นเว็บแอปพลิเคชันที่ช่วยเชื่อมโยงเกษตรกรและผู้รับซื้อสินค้าเกษตรเข้าด้วยกัน โดยใช้เทคโนโลยีปัญญาประดิษฐ์ (AI) เพื่อช่วยวิเคราะห์ข้อมูลและสนับสนุนการตัดสินใจซื้อขาย

สินค้าเป้าหมายในระยะแรก

-ข้าว

---

## ปัญหาที่ต้องการแก้ไข

เกษตรกรจำนวนมากประสบปัญหา

- ตั้งราคาสินค้าไม่เหมาะสม
- ไม่ทราบราคาตลาดปัจจุบัน
- หาผู้รับซื้อได้ยาก
- ถูกกดราคาจากพ่อค้าคนกลาง

โครงงานนี้จึงพัฒนาระบบตลาดกลางที่ช่วยให้ผู้ซื้อและผู้ขายสามารถเข้าถึงข้อมูลที่เป็นประโยชน์มากขึ้น

---

## วัตถุประสงค์

1. พัฒนาเว็บแอปพลิเคชันสำหรับซื้อขายสินค้าเกษตร
2. พัฒนาระบบ AI แนะนำราคาสินค้า
3. พัฒนาระบบ AI จับคู่ผู้ซื้อและผู้ขาย
4. แสดงข้อมูลสถิติและแนวโน้มตลาดผ่าน Dashboard

---

## ฟังก์ชันหลักของระบบ

### ผู้ขาย

- สมัครสมาชิก
- เข้าสู่ระบบ
- ลงประกาศขายสินค้า
- ดูราคาที่ AI แนะนำ

### ผู้ซื้อ

- ค้นหาสินค้า
- เปรียบเทียบราคา
- ดูคำแนะนำผู้ขายที่เหมาะสม

### ระบบ AI

- แนะนำราคาสินค้า
- จับคู่ผู้ซื้อและผู้ขาย

### Dashboard

- สรุปจำนวนสินค้า
- สรุปข้อมูลการซื้อขาย
- แสดงแนวโน้มราคา
